the domain is the set A of all possible inputs, the codomain is the set B of all possible outputs the function can take, and the range is the actual set of outputs the function produces when applied to every input in the domain. The range is always a subset of the codomain, but it may not be equal to it, as the codomain can include values that the function never actually produces.
